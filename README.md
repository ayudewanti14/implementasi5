# implementasi5
Dashboard Evaluasi Usability Berbasis IMK
Proyek ini merupakan implementasi dashboard interaktif menggunakan Python di Google Colab untuk mengevaluasi usability berdasarkan tingkat keberhasilan tugas, waktu pengerjaan, kepuasan pengguna, dan skor System Usability Scale (SUS).

Dashboard dilengkapi visualisasi data dan filter interaktif berdasarkan perangkat serta pengalaman pengguna. Dataset yang digunakan merupakan data simulasi untuk keperluan pembelajaran dan dapat dikembangkan menggunakan data pengguna sebenarnya.
